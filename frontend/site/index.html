Paste a discussion. See which accounts act as one.

How it works

We read the discussion and each participant's newest public posts through Context.dev, then look for accounts that share the same content far more often than chance. Public data only, no login. The result gets a private link and is deleted after 3 hours.

Bluesky, Hacker News, YouTube and Discourse give the whole thread; Mastodon the replies its server has seen; Reddit about 25 comments (use “Saved Reddit page” for more). Review pages and other forums with standard comment markup: one page, without the commenters' other posts.

How to save a Reddit page
  1. Open the thread on reddit.com and click “View more comments” a few times.
  2. Save the page: Ctrl+S (Mac: ⌘+S), and choose the .html file here.
Expected file format

Header on the first line, comma or semicolon separated. Only username is required; add text, links, repost_of, parent_id, timestamp, comment_id as you have them. The optional profiles file has username, created_at and label (human / bot, used only to measure). UTF-8, at most 20 MB together; you can also drop the files on the page. Full list in docs/api.md.

Try it: synthetic_comments.csv + synthetic_profiles.csv (simulated data). An uploaded file becomes the shared demo result every visitor sees.

How to read the map

One bubble per swarm, one dot per account. Coloured dots are flagged; white dots are linked to the group but copy far less, so they are not accused. The number under each swarm is its confidence: how much of their posts the group shares, not a probability.

When is an account flagged?

When it is in a group of at least 3 accounts that share content more often than chance predicts, and enough of its own content is shared with the group. A harmless automated feed that posts the same wire text looks exactly like a swarm, so check the evidence. Use this to monitor accounts, never to ban or restrict them.
