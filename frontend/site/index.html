Expected CSV format

First line is the header. One row per post. Separator comma (semicolon also works); quote text that contains the separator.

ColumnRequiredMeaning
idyesUnique per post.
accountyesThe author's stable id or handle.
timestampyesISO 8601, e.g. 2026-11-01T10:00:00Z. Without an offset it is read as UTC.
textyes (may be empty)The post text. Links inside it are found automatically.
linksnoURLs separated by a space or |.
repost_ofnoId of the reposted post.
coordinatednotrue/false: the known label. Needed for the metrics. Leave empty when unknown.
syntheticnotrue for simulated posts.

Summary

This data is simulated. Results on it show that the code works, not how good the detection is on real traffic.

Flagged accounts

Flagged = posted the same content within 60 seconds of another account on at least 3 separate occasions, in a linked group of at least 3 accounts. A flag is a lead to check, not proof: automated news feeds posting the same headlines look the same to these rules.
