# Data

Where every dataset we used comes from, its terms, and how we handle it. **No raw dataset is in this repository.**
Raw files live only on the machine of the person who ran the test, in `data/raw/` or `backend/data/` (both ignored
by git). Test reports in `docs/` hold aggregate numbers only: no usernames, no account ids, no texts.

Written 15.11.2026 by the backend owner, taking over from the data owner. Where a licence is not stated by the source,
we say so and treat the data as **research use only**.

## Rules for every real dataset

- Never commit it, quote it, or serve it from the live site. Only aggregate numbers leave the machine.
- Labels measure the detection; they never train it. The confidence cut is the one value chosen with labels visible.
- A result file of real data is published only anonymised and checked (`examples/anonymise.py`, `examples/README.md`).
- Synthetic and planted data is labelled as simulated, in the data and wherever it is shown.
